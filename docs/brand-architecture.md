# Brand Architecture

The public-facing project name is **OK Brokers**.

The product surface is the **Terminal Floor**: a StonkPit-inspired browser-work loop where OK Computers clock in, perform shifts, print `$BLANK`, and route protocol revenue into `$BNKR` rewards.

The original working name, **Machine Anvil**, remains useful as the name of the core protocol mechanism: the OK Computer NFT ↔ native token market / vault architecture.

## Naming Stack

| Layer | Name | Purpose |
| --- | --- | --- |
| Public brand | OK Brokers | The marketable project and website identity |
| App surface | Terminal Floor | Clock-in / browser-work / shift interface |
| Core mechanism | Machine Anvil | OK Computer NFT ↔ token market architecture |
| Native token | `$BLANK` | Work/fuel/ticket token printed by terminal shifts |
| Primary reward | `$BNKR` | Main reward asset routed from protocol revenue |
| Main pair | `$BLANK / $BNKR` | Liquidity alignment with the Bankr ecosystem |
| Reward router | Reward Router / BNKR Desk | Routes modeled fees into BNKR, ETH, USDG, and future eligible desks |
| User action | `clockIn()` | Start or settle a terminal shift |
| Optional premium rail | Stock Desk | Eligible-region-only stock-tokenized asset routing module |

## Positioning

```text
Clock your OK Computer into the Terminal Floor. Mine $BLANK. Stack $BNKR.
```

## Independence Language

Use:

```text
An independent community-built protocol concept inspired by OK Computers, StonkPit-style browser-work loops, and the Bankr/onchain-agent ecosystem.
```

Avoid:

```text
Official OK Computers product.
Official Bankr integration.
Endorsed by dailofrog or Bankr.
Universal stock-token rewards.
Guaranteed yield.
```

## Current Product Thesis

- OK Computers are terminal identities.
- The Terminal Floor gives holders an active loop: clock in, run browser work, print `$BLANK`.
- `$BLANK` is the native work/fuel/game token, not the primary value promise.
- `$BNKR` is the primary reward asset because it already has Bankr ecosystem relevance.
- Stock-token routing is optional and jurisdiction-gated; BNKR/ETH/USDG remain default rails.
- Machine Anvil stays below the surface as the market/custody/accounting mechanism.
